# Ideenkarte

Eigene Desktop-App zum Durchstöbern von Projekt- und Ideen-Ordnern. Links der Ordnerbaum,
rechts der Text. Mehrere Projekte, jedes ein eigener Ordner auf dem PC.

## Einmalig einrichten

1. Node.js installieren (LTS-Version): https://nodejs.org
2. Eingabeaufforderung öffnen (Startmenü → «cmd» eingeben → Enter).
3. In den Projektordner wechseln:
   ```
   cd C:\Users\chris\Documents\Ideenkarte
   ```
4. Abhängigkeiten installieren (dauert ein paar Minuten):
   ```
   npm install
   ```

## Starten

```
cd C:\Users\chris\Documents\Ideenkarte
npm start
```

Beim ersten Start: oben links auf «+ Projekt» klicken und einen Ordner wählen, z.B. den
Ordner deiner D&D-Story. Danach merkt sich die App alle Projekte.
